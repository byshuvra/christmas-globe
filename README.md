# Christmas Globe

An interactive 3D ASCII snow globe in a single, self-contained HTML file — zero frameworks, zero external assets, zero dependencies.

## Features

- **3D ASCII Point Cloud** — Depth-sorted fir tree, ornaments, star, and wooden pedestal rendered in real time on HTML5 Canvas.
- **Write a Wish & Send** — Write a personal wish (with a shooting-star arc) and share your exact globe (gifts, ornaments & wish) via link.
- **Shake** — Swirls a wind-driven snowstorm contained inside the glass dome.
- **Glyphs** — Switch the entire scene between `classic`, `kana`, `braille`, and `blocks`.
- **Moods** — Shift the tree, aurora, and lights between `pine`, `frost`, and `ember`.
- **Sound** — Synthesized chiptune *Jingle Bells* (Web Audio API) with beat-synced tree lights and gentle bell tings.
- **Poster · PNG** — Export a framed high-res PNG poster of your current scene, complete with a QR code.
- **Interactive Gestures** — Drag to spin & tilt, swipe fast for a sparkler trail, or tap the glass for a light ripple.

## Run Locally

Just open `christmas-globe.html` (or `index.html`) in any modern browser.
